# Matrice de couverture — fusion bibliographique

État de travail : 25 septembre 2026.

Objectif : construire d'abord une version **superset** de la partie bibliographique. Les deux thèses déjà présentes dans le dépôt et les cinq tables des matières photographiées servent de **check-list de thèmes**, pas de texte à recopier. Les sections seront ensuite réduites avec l'encadrant.

## Règles de fusion

- Conserver le noyau scientifique actuel : préparation/caractérisation des extraits, performances, sang/immunité, intestin/microbiote et synthèse critique.
- Ajouter tout thème bibliographique pertinent rencontré dans au moins une source d'inspiration.
- Éviter les doublons : un thème apparaît une seule fois dans le plan maître, même s'il existe dans plusieurs anciennes thèses.
- Actualiser le contenu avec des sources scientifiques vérifiables ; les anciens mémoires servent principalement à définir le périmètre.
- Ne pas importer les protocoles expérimentaux des anciennes thèses dans l'étude de Mohamed.
- Distinguer explicitement les propriétés générales de la feuille d'olivier des effets démontrés chez le poulet.
- Conserver les sections potentiellement secondaires pendant cette phase ; l'élagage interviendra après retour de l'encadrant.
